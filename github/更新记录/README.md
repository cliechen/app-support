## 写新记录时的约定

- 文件名：`YYYY-MM-DD-<主题>.md`。
- 必含章节：目标站点、当日提交表、改动明细（带文件:行号依据）、与代码核对结论、待办、继续工作入口。
- 文案改动必须能追到代码位置；无法核对的部分要写明「未验证」。
- 不写明文 PAT、API Key、密码。
